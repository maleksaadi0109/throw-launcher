---
name: Browser and provider choices
description: Product distinction between choosing Chrome and choosing Google Search.
---

Keep browser selection and search-provider selection independent. “Google” may mean Google Chrome to a user, not Google Search; clarify through distinct settings rather than changing Windows associations.

**Why:** The requested browser option is intended to let users open direct links in Chrome without changing their Windows default, keyword searches, or file actions.

**How to apply:** Future browser options should preserve this distinction and label the browser and search provider explicitly.
