# Throw Launcher identity

An original rounded **T / forward gesture** mark for Throw Launcher.

- `throw-launcher.svg`: scalable vector master, generated with QuiverAI.
- `throw-launcher.png`: 1024 × 1024 PNG with transparent corners.
- `throw-launcher.ico`: 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256-pixel Windows frames.
- Palette: sapphire blue and white.

`desktop/throw-rust/branding/render-branding.py` reproduces the raster assets
from the SVG using build-time CairoSVG and Pillow; neither is a runtime dependency.

The mark is used in the README and desktop application icon assets. It is
distinct from Flow Launcher’s original identity. This does not imply trademark
registration or endorsement by the upstream project.
