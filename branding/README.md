# Throw Launcher identity

An original geometric **T / outward arrow** mark for the Throw Launcher fork.

- `throw-launcher.svg`: scalable vector master, generated with QuiverAI.
- `throw-launcher.png`: 512 × 512 transparent PNG.
- `throw-launcher.ico`: multi-resolution Windows icon.
- Palette: warm orange `#FD662B`, deep ink `#122021`.

The mark is used in the README and desktop application icon assets. It is
distinct from Flow Launcher’s original identity. This does not imply trademark
registration or endorsement by the upstream project.
